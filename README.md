# Binance Scanner — تطبيق أندرويد

فاحص لسوق باينانس (سبوت، إشارات شراء فقط). التطبيق **لا ينفّذ أي أوامر** — الإشارات تحليلية فقط.

## الملفات
| الملف | الوظيفة |
|---|---|
| `main.py` | الواجهة (Kivy): قائمة الاستراتيجيات + الكونسول + الإعدادات |
| `scanner_v5.py` | استراتيجية: فحص بدون فلتر صاعد (V5) |
| `scanner_htf.py` | استراتيجية: فحص بفلتر اتجاه 4h |
| `pdlite.py` | بديل خفيف لـ pandas (عشان pandas مش بيتبني على أندرويد) |
| `binance_utils.py` | أدوات جاهزة لكتابة استراتيجيات جديدة (شموع، مؤشرات، طباعة الإشارة) |
| `strategies/` | هنا بتحط استراتيجياتك الجديدة |
| `buildozer.spec` | إعدادات بناء الـ APK |

## إضافة استراتيجية جديدة (من غير ما تلمس main.py)
1. انسخ `strategies/strategy_ema_cross.py` باسم جديد: `strategies/strategy_<اسمك>.py`
   (لازم الاسم يبدأ بـ `strategy_`).
2. عدّل `NAME` و `DESC` (الاسم والوصف اللي هيظهروا في الكارت) ودالة `analyze`.
3. ارفع الملف على GitHub → يبدأ البناء → بعد التثبيت يظهر كارت جديد لوحده.

أي استراتيجية لازم يكون فيها:
```python

DESC = "وصف قصير\nسطر تاني"
def scan_all():
    ...  # اطبع النتايج بـ print
```
نصايح:
- استخدم `bu.check_stop()` داخل اللوب و `bu.sleep(0.1)` بدل `time.sleep` عشان زر الإيقاف يشتغل فوراً.
- اطبع الإشارة بـ `bu.report_buy(...)` يطلع بالشكل القياسي ويتحفظ في ملف `signals_custom.jsonl`.
- لو الاستراتيجية فيها خطأ برمجي، بتظهر في القائمة بكارت أحمر وباقي التطبيق يفضل شغال.
- مكتبات متاحة: `numpy` و `requests` فقط. لو محتاج مكتبة تانية لازم تتضاف في `requirements` وتتجرب.

## الإعدادات داخل التطبيق
- **وضع العربي**: لو العربي ظاهر معكوس أو بحروف مقطعة، بدّل الوضع لحد ما المعاينة تبقى صح.
- **إخفاء المرفوضات**: بيخفي سطور الأزواج المرفوضة وبيخلي الشاشة أسرع.

## ملاحظات
- الفحص بيشتغل طول ما التطبيق مفتوح على الشاشة. لو خرجت منه أندرويد ممكن يوقفه.
- زرار **نسخ النتائج** بينسخ كل الكونسول للحافظة.
